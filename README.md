# 🌿 La Forêt des Codes — Genuary 2026
 
> *"Je suis née là où le premier algorithme a touché la terre."*
> — Sylva, esprit de la forêt
 
## ✦ À propos
 
**La Forêt des Codes** est un site génératif créé dans le cadre du défi **Genuary 2026** — un défi mondial où les artistes créent une œuvre d'art génératif par jour durant tout le mois de janvier, chacune suivant une contrainte différente.
 
Ce site est ma forêt personnelle : 31 œuvres algorithmiques, chacune unique, chacune vivante.
 
---
## 🌲 Sylva — L'Esprit de la Forêt
 
Le site intègre **Sylva**, un chatbot non-IA gardienne des 31 Genuaries. Elle répond à tes questions sur les œuvres, le code génératif, et la forêt algorithmique.
 
Son agent IA est également disponible sur Eden.art.
