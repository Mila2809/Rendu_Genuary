## ✦ À propos
 
**La Forêt des Codes** est un site génératif créé dans le cadre d'un devoir où on a dû participer au défi **Genuary 2026**. C'est un défi mondial où les artistes créent une œuvre d'art génératif par jour durant tout le mois de janvier, chacune suivant une contrainte différente.
 
Ce site est ma forêt personnelle : 31 œuvres algorithmiques, chacune unique, chacune vivante.

## 🌲 Sylva — L'Esprit de la Forêt
 
Le site intègre **Sylva**, un chatbot IA gardienne des 31 Genuaries. Elle répond à tes questions sur les œuvres, le code génératif, et la forêt algorithmique.
 
Son agent IA est également disponible sur Eden.art.
